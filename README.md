# Clinic Frontend

الواجهة المتصلة بـClinic API، وتشمل عرض الأطباء، البحث والتخصصات، الحجز والإلغاء، التقييم وإرسال Feedback.

## التشغيل المحلي

يتطلب Node.js 22 أو 24 وPython 3 لتقديم الملفات محليًا. شغّل الباك أولًا على `http://localhost:62114` ثم نفّذ من جذر فرع `front-end`.

```powershell
npm ci
npm run build
python -m http.server 5500 --bind 127.0.0.1 --directory dist
```

افتح `http://127.0.0.1:5500`. الإخراج الجاهز للتقديم موجود في `dist`. إذا استضفت الواجهة على دومين مختلف، اضبط `PRODUCTION_API_URL` قبل البناء على عنوان HTTPS للـAPI ينتهي بـ`/api`، وأضف أصل الواجهة إلى CORS في الباك. هذا المتغير يُكتب في HTML ويُقرأ علنًا.

الربط الحالي للتجربة ببيانات وهمية، وهوية المريض مشتركة في الحجز وFeedback.

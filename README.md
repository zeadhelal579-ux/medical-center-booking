# Clinic | MedCare Portal

بوابة لتصفح الأطباء حسب التخصص، البحث، حجز المواعيد وإلغائها، تقييم الأطباء، وإرسال Feedback.

| الفرع | فولدر النسخة المحلية | المحتوى |
| --- | --- | --- |
| `main` | `clinic` | README العام |
| `back-end` | `back-end/clinic back` | ASP.NET Core API وFirestore |
| `front-end` | `front-end/clinic front` | الواجهة المتصلة بالـAPI |
| `front-Deploy` | `front Deploy/clinic front vercel` | الواجهة الجاهزة للبناء على Vercel، مع وضع Demo مستقل |

ملفات كل تطبيق موجودة في جذر فرعه. اسم فرع النشر يستخدم شرطة مكان المسافة لأن Git لا يقبل مسافات في أسماء الفروع.

للتجربة المحلية شغّل الباك على `http://localhost:62114`، ثم شغّل الواجهة العادية على البورت `5500` أو واجهة النشر على `5501`. افتح `/?demo=1` على واجهة النشر لتجربة البيانات الوهمية المستقلة. تعليمات التشغيل والتهيئة في README كل فرع.

الربط المحلي اتجرّب ببيانات وهمية على Firestore Emulator. استخدم وضع Demo العام بدون API. الواجهة المتصلة والـAPI يستخدمان هوية مريض مشتركة ويحتاجان تسجيل دخول وصلاحيات لكل سجل قبل استقبال بيانات حقيقية.
